# Estructura del repositorio

- `app/`: rutas, layouts y endpoints de Next.js.
- `components/`: interfaz, secciones, ilustraciones y sistema de temas.
- `lib/`: dominio, seguridad, integraciones y acceso a datos.
- `messages/`: traducciones por idioma.
- `public/`: archivos públicos y recursos de descubrimiento.
- `supabase/`: migraciones y funciones de base de datos.
- `tests/`: pruebas unitarias y end-to-end.
- `scripts/`: validación, despliegue y carga controlada.
- `docs/architecture/`: decisiones y estructura técnica.
- `docs/product/`: principios, arquitectura de producto y recursos de marca.
- `docs/operations/`: operación, alertas y despliegue.
- `docs/reference/`: material histórico o de consulta.

Los directorios generados (`.next`, `coverage`, `test-results`) no forman parte del producto ni deben versionarse.
